# Basant Kumar Mehta — Portfolio

A premium, dark, engineering-focused portfolio inspired by the structure and feel of the reference portfolio shared by Basant.

## Stack

- Next.js
- TypeScript
- Framer Motion
- Lucide React
- CSS

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Before deployment

1. Put your resume at `public/Basant_Updated_Resume.pdf`
2. Replace `YOUR_EMAIL@example.com` in `app/page.tsx`
3. Replace the LinkedIn and GitHub URLs with your real profiles.
4. Update the "Previous Experience" entry with the exact companies/dates from your resume.
5. Deploy to Vercel.

The design intentionally avoids copying the reference site's exact text/assets and instead uses the same broad portfolio pattern with original content and styling.
